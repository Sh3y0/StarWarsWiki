# StarWarsWiki
Star Wars Characters Gallery and More

Monorepo with three apps:

- [`apps/backend`](apps/backend/README.md) — Node.js + TypeScript + Fastify API that syncs the StarWars.com Databank.
- `apps/mobile` — React Native app (TODO).
- `apps/web` — React Web site (TODO).

## Quickstart

```bash
npm install
npm run backend:dev
```
